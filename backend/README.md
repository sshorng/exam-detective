# 錯題熱點後端部署（Google Apps Script）

一份試算表服務所有考卷，部署一次之後不必再動。

## 四步部署

1. 開一份新的 Google 試算表，命名例如「考場抓鬼大師回報」。
2. 在試算表選「擴充功能 → Apps Script」，把 `Code.gs` 全部內容貼進編輯器並存檔。
3. 右上角「部署 → 新增部署作業」：
   - 類型選「網頁應用程式」。
   - 執行身分選「我」。
   - 具有存取權的使用者選「任何人」。
   - 按部署，依指示授權。
4. 複製產生的 `/exec` 網址，回到 `index.html`，把網址填進 `Hotspot` 的 `GAS_URL` 常數：

```js
      GAS_URL: "https://script.google.com/macros/s/AKfy.../exec",
```

填好後重新整理網頁，頁首「錯題熱點」按鈕即可使用。

## 第一次執行會自動建立三張工作表

| 工作表 | 內容 |
|:---|:---|
| 回報 | 時間、批次、考卷、版本、班級、座號、題號、客戶端 |
| 歷史 | 清空時間、層級，加上回報表的全部欄位 |
| 設定 | `B1` 是教師密碼，首次自動產生 8 碼隨機值 |

教師密碼就在「設定」工作表 `B1`。想換密碼直接改這一格，改完網頁要重新輸入一次。

## 驗證後端是否活著

在瀏覽器打開 `/exec` 網址，看到下面這段就代表部署成功：

```json
{"ok":true,"ver":"hotspot-1"}
```

## 常見問題

- **統計頁顯示「尚未接上後端」**：`GAS_URL` 沒填或填錯，注意結尾要是 `/exec` 而不是 `/dev`。
- **回報後試算表沒有資料**：先確認部署的存取權是「任何人」。若學生端離線，資料會暫存在該臺平板，下次開頁才補送。
- **改了題庫，舊資料還在**：題庫版本 `qbVersion` 由題數與題號決定，統計只算當前版本。舊資料請用第二層清空。
- **換班級要清空**：用第一層清空，資料會先歸檔到「歷史」再清掉目前資料。
- **學期末大掃除**：用第三層清空，需輸入「確定清空」，同樣先歸檔。

## 隱私

送到這裡的只有班級、座號（可留空）、題號與一組隨機客戶端碼。不含姓名，也不含學生選了哪個選項。班級加座號仍可對應到個人，若不想要這層可對應性，請要求學生座號留空。
